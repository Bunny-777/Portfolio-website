# Kushagra Shrivastava - Personal Portfolio

A sleek, modern developer portfolio built with React, TypeScript, Framer Motion, and Vite.

## Tech Stack
- **Frontend**: React 19, TypeScript, Framer Motion, Vanilla CSS
- **Bundler**: Vite
- **Deployment**: Vercel / GitHub Pages

## Features
- Interactive Terminal emulator with commands (`about`, `projects`, `skills`, `resume`, `contact`)
- Dark themed interactive UI with cosmic ambient background
- Experience & Projects showcases with live repository links
- Mobile responsive navigation and quick resume access
